# Security Policy

## Scope

This repository explores security platform architecture and implementation patterns.

## Reporting

If you discover a vulnerability in this repository or its examples, do not open a public issue with exploit details.

Instead, report it privately to the maintainer through a private channel configured for the published repository.

## Secure development expectations

- minimize secret exposure in code and test fixtures
- document trust boundaries
- prefer least privilege in deployment examples
- treat scanner and remediation modules as high-risk components
