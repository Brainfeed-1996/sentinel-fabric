# FAQ

## Is this meant to be production-ready today

No. It is a serious engineering project intended to evolve into a production-grade architecture.

## Is this a SIEM

No. It overlaps with some visibility concerns but focuses on exposure management, posture, correlation, and remediation workflows.

## Why this project is useful for a portfolio

It demonstrates security engineering, architecture judgment, data modeling, system design, and documentation discipline in one place.
