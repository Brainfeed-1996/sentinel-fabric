# Operator Workflows

## Triage workflow

1. review high-severity findings
2. inspect linked assets and evidence
3. validate exploitability or business impact
4. assign remediation owner
5. track status transitions and verification

## Exposure review workflow

1. ingest or refresh exposure data
2. correlate with asset criticality and ownership
3. score and rank exposures
4. open remediation workflow when thresholds are crossed
